# Configuración de Usuario

La configuración de usuario es tu portal a todas las configuraciones que puedes ajustar en el bot. Aquí puedes controlar qué notificaciones recibes, configurar la creación de hongos, editar tu [alerta de hongos](alarm.md) y [gestionar tu perfil](profile.md).

!!! warning ""

    Actualmente todavía estamos desarrollando el concepto de cómo estar activo con el bot **en múltiples grupos de hongos**. Por lo tanto, las funciones mostradas aquí pueden cambiar en el futuro. Intentamos mantener esta guía siempre actualizada.

## Notificaciones

![Notificaciones](assets/screenshot/notifications.png){ width="30%" align="right"}

### Noticias

De vez en cuando, los desarrolladores escriben un boletín y lo envían a todos los usuarios activos. Este mensaje se elimina automáticamente después de algún tiempo para limpiar tu chat del bot. Si no quieres recibir estos mensajes, puedes desactivarlos aquí.

### Menciones

Si alguien escribe una respuesta a tu mensaje de hongo en el grupo, serás informado inmediatamente por el bot. Si no deseas recibir estas notificaciones, se mostrará una campana tachada :no_bell: en tu mensaje de hongo para que otros sepan que no serás notificado directamente. Si la respuesta al mensaje de hongo comienza con un símbolo @, tampoco serás notificado, ya que probablemente tú u otros jugadores fueron dirigidos directamente.

### Alerta de Hongos

Puedes usar la [función Alerta de Hongos](alarm.md) para ser informado sobre hongos deseados. Aquí puedes activar y desactivar la Alerta de Hongos. También puedes desactivar la Alerta de Hongos directamente en la notificación del hongo; este es el lugar correcto para volver a activarla si lo deseas.

!!! info ""
    
    Si desactivas la Alerta de Hongos, tu deseo de hongo ya no se mostrará en la [lista de hongos activos](active.md).

### Silenciar Alerta Hasta Mañana

!!! tip "Función para Partidarios"

    Esta función actualmente solo está disponible para [partidarios](support.md).

Si has terminado con tus hongos por hoy, puedes silenciar la Alerta de Hongos hasta mañana. Aquí también puedes establecer la hora a partir de la cual quieres buscar hongos nuevamente.
