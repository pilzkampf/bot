# Bienvenido al Pilzkampf Bot

El **Pilzkampf Bot** en Telegram te ayuda a encontrar compañeros de equipo para **Pikmin Bloom**.  
Puedes acceder a él en [https://t.me/pikminpilz_bot](https://t.me/pikminpilz_bot).

!!! info "Beneficios del Pilzkampf Bot"

    - Recibes **códigos de amigo** de otros jugadores automáticamente.
    - Todos los jugadores invitados pueden ver **cuánto tiempo queda** en la batalla de hongos
      y **quién ya se ha unido**.
    - Puedes **recibir notificaciones** cuando se encuentre una batalla de hongos que coincida.

!!! info "¿Qué significa el nombre?"

    **Pilzkampf** (pronunciado *"pilts-kampf"*) es alemán para "batalla de hongos" -
    una elección deliberada que refleja tanto la funcionalidad del bot como su herencia.
    Aunque "bot de batalla de hongos" sería la traducción directa, mantuvimos el nombre alemán
    para honrar a la comunidad que lo creó y porque *Pilz* simplemente se siente adecuado
    para los entusiastas de Pikmin Bloom.

!!! info "Privacidad"

    El bot no puede leer todos tus mensajes porque el **Modo de Privacidad** está activado.
    Solo reacciona a comandos específicos o mensajes que son respuestas directas al bot.
    Para más información, consulta [Privacidad](privacy.md).

## Primeros Pasos

Haz clic en el enlace de arriba o busca **"Pilzkampf Bot"** en Telegram.  
Si nunca has interactuado con el bot antes, presiona el gran botón **INICIAR** de abajo.
Esto activa el bot y le permite enviarte mensajes.

Después, recibirás una breve introducción que explica
cómo registrar tu **nombre de jugador de Pikmin Bloom**.
También puedes proporcionar tu **nivel** y **código de amigo**.

!!! info "Tu Nivel y Código de Amigo"

    - Tu nivel se utiliza para **estimar el tiempo restante** de una batalla de hongos
      cuando creas una.  
      Si no has ingresado un nivel, el bot asume **nivel 60** por defecto.
      También puedes elegir **ocultar tu nivel** a otros jugadores
      en la [Configuración de Perfil](profile.md).

    - Tu código de amigo se **comparte automáticamente** cuando te unes a una batalla
      con alguien con quien aún no eres amigo en Pikmin Bloom.
      Aprende más en [Unirse a una Batalla de Hongos](battle.md).

Para prevenir spam y mal uso, debes **verificarte**.
Recibirás un código de amigo que puedes usar para conectarte con el bot.
Si aún no estás en un grupo de Telegram donde el bot esté activo,
se te contactará y guiará a uno.

!!! info "Grupos de Batalla de Hongos"

    El bot es solo una herramienta — **la comunidad es lo que lo hace especial**.
    Obtendrás el máximo provecho usándolo **en un grupo activo de Pilzkampf**.

## Comandos Importantes

Todos los comandos del bot comienzan con una barra diagonal **"/"**.  
Los más importantes para principiantes son:

* `/pilz` – Crear una nueva batalla de hongos
* `/active` – Mostrar la lista de batallas activas
* `/alarm` – Configurar notificaciones para tipos de hongos o horarios que te interesen

Muchos comandos también están disponibles a través del **menú** en la parte inferior izquierda
(en el chat privado) o inferior derecha en el **chat grupal** :material-slash-forward-box:.

Algunos comandos pueden no aparecer inmediatamente.  
Para una lista completa, consulta [Comandos](commands.md).
También puedes personalizar tu menú de comandos en la [Configuración de Perfil](profile.md).

## Próximos Pasos

Para comenzar de inmediato, consulta
[**Unirse a una Batalla de Hongos**](battle.md).
Allí aprenderás cómo unirte a una batalla existente o crear la tuya propia.

Para obtener una descripción general de todas las funciones disponibles, consulta [Comandos](commands.md).

El bot puede hacer más que solo ayudar con las batallas:
puede recordarte sobre **eventos mensuales**
o configurar **temporizadores** cuando una batalla termina o una expedición regresa.

Si tienes problemas o sugerencias,  
hay un **grupo de soporte** donde puedes obtener ayuda rápida.

!!! warning "Problemas Comunes"

    A veces Telegram retrasa la entrega de mensajes o el bot puede parecer lento para responder.
    Estamos trabajando constantemente para mejorar el rendimiento.

    Cuando el bot solicita una entrada de texto, inicia una **sesión** para vincular tu respuesta.
    Si esta sesión expira (generalmente después de 90 segundos), pueden ocurrir errores.
    En ese caso, por favor usa el comando **`/cancel`** e inténtalo de nuevo.
