# List of Active Mushrooms

![List of Active Mushrooms](assets/screenshot/active.png){ width="30%" align="right"}

The list of active mushrooms gives you a quick overview when you want to see which mushroom battles are currently available.
It updates in real time and shows both newly offered battles and those you are currently participating in. If you don’t close the message yourself, it will disappear automatically after one hour.

If there are open mushroom battles in your group, you’ll see their size and type. You can also follow a link directly to your chat group to apply for the battle.

At the end of the list, you’ll find mushroom requests created by other players using their [Mushroom Alert](alarm.md). This helps you estimate how many players might join before you post a new mushroom offer.

By default, the list does not show battles that only have ticket slots available.
However, if you tap **“Show with ticket”**, those battles will also be displayed. This button only appears when such offers exist. The other button takes you directly to the [Mushroom Alert](alarm.md).
