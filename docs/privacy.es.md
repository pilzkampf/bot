# Privacidad

Para proporcionar el servicio, el bot necesita acceder y almacenar algunos datos. Todos los datos se procesan en un servidor en Alemania; ninguno de estos datos se comparte con otras personas o partes. El único propósito de los datos es proporcionar el servicio "Pilzkampf Bot". Adicionalmente, se aplica la [Política de Privacidad de Telegram](https://telegram.org/privacy), sobre la cual no tenemos influencia.

## Datos Permanentes

Mientras uses el bot, los siguientes datos se almacenarán permanentemente:

| Datos | Razón |
|-------|-------|
| Nombre de jugador, Nivel, Código de amigo | Estos datos son proporcionados por el usuario y son importantes para la comunicación entre jugadores y para evaluar la batalla de hongos. El nivel y el código de amigo son datos opcionales y pueden dejarse en blanco. Todos estos datos pueden ser cambiados por el usuario en cualquier momento. |
| ID de Telegram, Nombre para mostrar, Nombre de usuario | Estos datos son proporcionados por Telegram. El jugador puede cambiar su nombre para mostrar y nombre de usuario en Telegram en cualquier momento. El ID único de Telegram es necesario para identificar de manera única a los jugadores cuando su nombre cambia. |
| Zona horaria, Idioma | El usuario puede establecer el idioma y la zona horaria por sí mismo. Si no se establecen idioma y zona horaria, se utiliza un valor predeterminado. Estos datos son importantes para personalizar los mensajes para el usuario y mostrar los horarios de acuerdo con su hora local. |
| Fecha de registro y fecha de última actividad | Estos datos son importantes para mejorar el servicio del bot e identificar jugadores que ya no usan el bot o nunca lo han usado. |

## Datos Temporales

El Pilzkampf Bot escribe archivos de registro y registra la actividad del bot para el desarrollador. El archivo de registro se utiliza para analizar problemas y errores con el bot, lo que ayuda a mejorar regular y continuamente el servicio. Los archivos de registro se eliminan permanentemente después de siete días.

Con el [comando `/logfile`](commands.md#comandos-de-administrador), los administradores también tienen la capacidad de identificar rápidamente problemas con una sola batalla de hongos. Estos datos solo están disponibles para administradores y desarrolladores.
